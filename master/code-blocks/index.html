    Adjacent code blocks with tab=<name> are shown as one block with a tab for each.

     1export function greet(name) {
 2    return `Hello, ${name}!`;
 3}

     1export function greet(name: string): string {
 2    return `Hello, ${name}!`;
 3}

     1npm install laravel-echo pusher-js

     1yarn add laravel-echo pusher-js

     1pnpm add laravel-echo pusher-js
