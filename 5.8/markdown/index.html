    Text

    Text can be bold, italic, bold and italic, struck through, or inline code. Combine them: bold with code inside and italic with a link.

    Special characters are escaped: *not italic*, 5 < 10, and © 2026.

    Math

    Inline math \(E = mc^2\), \(\sqrt{3}\) with backticks, and \(a_{ij}\) with braces.

    A display block:

    \[ \sum_{i=1}^{n} i = \frac{n(n+1)}{2} \]

    A math code block:

    \[\int_0^1 x^2 \, dx = \frac{1}{3}\]

    These stay as written: $5 and $10, the $user variable, a hash $2y$10$abc, and $x$ in code.
